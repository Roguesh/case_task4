# Кейс-задача №4: Юнит-тестирование структур данных

## Описание
Проект представляет собой набор юнит-тестов для следующих структур данных:
* Очередь (Queue)
* Куча (Heap)
* Бинарное дерево (BinaryTree)

## Требования
* Google Test framework
* C++11 стандарт

## Установка и запуск

### Требования
* CMake
* Google Test
* GCC/Clang компилятор

### Инструкция по сборке
```bash
mkdir build
cd build
cmake ..
make
./runTests
